# Social Intel And Horizontal Comparison / 社区攻略与横向对比

Use this reference when reading Xiaohongshu/REDnote, Zhihu, Reddit, blogs, Discord/forum posts, store pages, weekly ads, or user-provided screenshots to improve cost-performance decisions. The goal is not to copy community advice; it is to turn messy posts into verified, personalized, comparable choices.

## Source Access / 来源访问

- Browse/search when the user asks for current prices, current store hacks, today's/this week's deals, local store comparisons, or recent community advice.
- If a platform is gated, personalized, or inaccessible through public browsing, ask the user for links, screenshots, or pasted text.
- For Reddit, prefer direct thread links, subreddit search, and recent comments when the question is community-experience based.
- For Xiaohongshu/REDnote and Zhihu, treat posts as anecdotal unless multiple recent posts agree or a price/store page confirms it.
- For official store pages, weekly ads, product pages, nutrition labels, and food-safety pages, prefer them over community claims.
- Respect platform terms and copyright. Do not provide long verbatim excerpts; summarize and cite/link.

## Claim Extraction / 攻略信息抽取

Extract every useful post into this table shape:

| Field / 字段 | What to capture / 抽取什么 |
|---|---|
| Source / 来源 | Platform, link, author/community if visible |
| Date / 日期 | Published/updated date; mark unknown if absent |
| Location / 地点 | City/country/store; mark if not the user's region |
| Claim / 主张 | "Aldi chicken thighs are cheapest", "Costco rice wins if you have freezer/storage", etc. |
| Price / 价格 | Shelf price, unit price, serving count, package size |
| Conditions / 条件 | Membership, coupon, car access, freezer space, cookware, dietary fit |
| Hidden cost / 隐形成本 | Travel time, bulk waste risk, one-use sauces, storage, spoilage |
| Safety/health flag / 安全健康 | Raw food, allergens, high sodium, risky leftovers, unclear storage |
| Confidence / 可信度 | High/medium/low and why |

## Verification Ladder / 验证优先级

1. Official safety sources: USDA/FDA or local public health.
2. Official store price/page/weekly ad/nutrition label.
3. Multiple recent community posts from the user's region.
4. One recent detailed post with receipts/photos and clear location.
5. Old, vague, or viral posts with no numbers.

If evidence conflicts, say so and choose conservatively.

## Horizontal Comparison / 横向对比方法

Compare options by normalized, user-specific value rather than vibe:

- Cost per serving / 每份成本: total usable cost divided by realistic servings.
- Unit price / 单位价格: normalize pounds, ounces, grams, packs, and edible yield.
- Time cost / 时间成本: travel + active cooking + cleanup + queue time.
- Waste risk / 损耗风险: fragile produce, huge packages, short shelf life, no freezer.
- Reuse score / 复用率: how many meals/cuisines the same ingredient supports.
- Nutrition fit / 健康适配: protein, veg/fiber, sodium/sugar/saturated fat, allergens.
- Safety risk / 安全风险: raw meat handling, storage uncertainty, reheating, high-risk users.
- Equipment fit / 设备适配: one pan, rice cooker, microwave, oven, freezer, car access.
- Joy score / 好吃和坚持度: user preference matters; cheap food wasted is not cheap.

Good recommendation formula:

`true value = low cost per serving + low waste + high reuse + health/safety fit + realistic time + user actually wants to eat it`

## Scoring Rubric / 打分

Use a 1-5 score unless the user asks for exact math:

| Category / 类别 | 1 point | 5 points |
|---|---|---|
| Cost / 成本 | Expensive per serving | Cheapest realistic serving |
| Time / 时间 | Long travel/cooking/cleanup | Fast and low friction |
| Reuse / 复用 | One-use item | Works across 3+ meals |
| Waste / 损耗 | High spoilage/bulk risk | Shelf-stable/freezable/finishable |
| Health / 健康 | Poor fit for goals | Strong fit |
| Safety / 安全 | Risky/unclear | Clear safe handling |
| Taste / 好吃 | User unlikely to enjoy | Strong preference fit |

Call out the winner by scenario:

- Cheapest now / 立刻最便宜
- Best weekly value / 一周综合最划算
- Best for no car / 无车最适合
- Best for no freezer / 没冰箱/冷冻最适合
- Best high-protein / 高蛋白最适合
- Best low-effort / 最省事

## Community Bias Checks / 社区攻略防坑

Watch for:

- Regional mismatch: a California Costco tip may not apply in Ohio.
- Old prices: inflation and weekly sales can flip rankings.
- Bulk illusion: big packages lose value without freezer/storage.
- One-time sauce trap: cheap recipe becomes expensive if it needs six new condiments.
- Aesthetic bias: pretty meal prep is not necessarily cheap, healthy, or repeatable.
- Hidden labor: washing/chopping/carrying bulk groceries matters.
- Health mismatch: viral "cheap" meals may be sodium-heavy or low in protein/fiber.
- Safety mismatch: comments may normalize unsafe thawing, room-temperature leftovers, or raw eggs.

## Output Pattern / 输出格式

For social-intel answers, output:

1. Search scope: platforms, region, dates, and any inaccessible sources.
2. Source matrix: summarized claims, not long quotes.
3. Horizontal comparison table: cost/serving, time, reuse, waste, health, safety, confidence.
4. Recommendation: best option for the user's constraints.
5. Action list: what to buy, where, package size, and fallback if price is different.
6. Uncertainty: what needs user confirmation, such as local price or membership.

## Example / 示例

User asks: "小红书说 Costco 鸡腿最划算，Reddit 说 Aldi 更便宜，我该去哪买?"

Answer structure:

- Ask: location, car/freezer, membership, meals/servings.
- Check official/current prices if browsing is available.
- Normalize price per edible serving.
- Add hidden costs: membership, travel, bulk freezing, spoilage.
- Decide by scenario: Costco wins for freezer + bulk prep; Aldi wins for small fridge/no car/low upfront cash.
